# Property & Asset Registry Service Skeleton

M0.1 establishes an independently configurable FastAPI process and `/health` endpoint. It does not yet implement asset models, CRUD, migrations, authentication, authorization, tenant isolation, or database persistence. `DATABASE_URL` is configuration only at this stage; the published Phase 2 property API remains in `backend/`.

See [local development](../../docs/local-development.md) for Docker Compose and test commands.
